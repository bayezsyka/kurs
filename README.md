# Kalkulator Kurs USD / IDR

Aplikasi komparasi kurs valas (USD ke IDR) untuk menghitung selisih nilai, estimasi laba/rugi, margin per dollar, serta simulasi target jual dan break-even.

## Fitur
- Komparasi Kurs A vs Kurs B dengan kalkulasi live real-time
- Kalkulasi selisih nominal (IDR), selisih per USD, dan persentase depresiasi/apresiasi
- Tombol swap / tukar posisi Kurs A & B
- Preset cepat nominal USD
- Referensi kurs pasar langsung via open exchange API
- Simulasi target kurs jual berdasarkan laba bersih yang diinginkan
- Perhitungan biaya transaksi / spread per dollar
- Penyimpanan riwayat skenario lokal di browser
- Salin ringkasan teks untuk pencatatan/berbagi

## Deploy
Dihosting di platform Farovel pada domain `https://kurs.sangkolo.my.id`.
